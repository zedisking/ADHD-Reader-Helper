# ADHD Reading Helper - Privacy Policy

**Last updated:** February 2025  
**Author:** Damien Cresswell

## Overview

ADHD Reading Helper is a Microsoft Edge extension that converts web pages and documents to Bionic Reading format. This privacy policy explains how the extension handles data.

## Data Collection

**ADHD Reading Helper does not collect, transmit, or share any personal information with external servers.**

All processing happens locally in your browser. The extension does not send your data anywhere.

## Data Storage

The extension uses Microsoft Edge's built-in storage (`chrome.storage.sync`) to save your preferences:

- **Strength setting** (1–5): How much of each word is bolded
- **Enabled/disabled state**: Whether the reading helper is active
- **Tag exclusions**: Which HTML elements to exclude from conversion (e.g. header, footer)

This data is stored locally in your browser and, if you are signed into Microsoft Edge, may sync across your devices via your Microsoft account. We do not have access to this data.

## Permissions

| Permission | Purpose |
|------------|---------|
| Storage | Save your preferences (strength, enabled state, tag settings) |
| Tabs | Reload pages when settings change; scan current page for tags |
| Scripting | Apply bionic reading to pages; scan for HTML tags |
| Host permissions | Run on web pages and local files you open |

## Document Uploads

When you upload a document (TXT, PDF, DOCX, ODT), the file is processed entirely in your browser. No document content is sent to any server. The extension reads the file locally and displays the converted text.
